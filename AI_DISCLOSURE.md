# AI Usage Disclosure

Sharp Filter Selector was developed with substantial assistance from generative AI.

## Scope of AI assistance

Generative AI was used to write a majority of the current codebase, including significant portions of:

- the Python backend;
- the Decky frontend;
- compatibility and portability changes;
- documentation and repository tooling.

The project was not produced as an unreviewed one-shot generation. The plugin originated from a concrete user-developed workflow and was iteratively refined through real-world testing, debugging and repeated changes based on observed behavior.

## Human involvement

The maintainer:

- defined the plugin's purpose and desired behavior;
- tested the plugin on real hardware and Linux gaming environments;
- verified FSR/NIS behavior and identified failures;
- provided runtime logs, environment details and reproduction steps;
- repeatedly tested revisions and requested corrections;
- made the decision to publish and maintain the resulting project.

## Why this file exists

This disclosure is intentionally public so users and reviewers can evaluate the project's provenance without ambiguity.

The maintainer will not claim that generative AI was *not* used to write a majority of the code. If a distribution platform or plugin store has rules regarding AI-generated code, this project should be evaluated under those rules with this disclosure in mind.

## Maintenance commitment

Regardless of how the code was produced, the repository is intended to be maintained as ordinary source code:

- bugs will be reproduced and fixed;
- compatibility changes will be tested;
- dependencies and licensing requirements will be reviewed;
- changes will remain publicly auditable in Git history.

This disclosure applies to the current public codebase and should remain part of the repository unless the provenance of the project materially changes.
