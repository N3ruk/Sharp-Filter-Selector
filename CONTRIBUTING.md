# Contributing

Contributions are welcome.

For bug reports, please include:

- SteamOS/Linux distribution and version.
- Decky Loader version.
- Gamescope version.
- Whether the issue occurs with FSR, NIS, sharpness, or session detection.
- Relevant Decky/plugin logs when available.

For code changes:

1. Fork the repository and create a branch.
2. Keep changes focused and avoid unrelated formatting rewrites.
3. Run `python3 -m py_compile main.py`.
4. Run `npm run build`.
5. Test the plugin in a real Gamescope session before opening a pull request.
